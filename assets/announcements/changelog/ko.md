**버전 2.0.0**

**1. 앱 이름 변경**

앱 이름을 「Amitabha Buddha」에서 「하루 염불」로 변경했습니다.

더 쉽게 찾을 수 있으면 하는 마음과 함께, 축복과 격려의 뜻도 담았습니다 ——「하루하루가, 염불하기 좋은 날.」

추천과 따뜻한 리뷰로 함께해 주시면 「하루 염불」이 필요한 분들께 닿을 수 있습니다.

**2. 사용 경험 개선**

- 음성 인식을 개선하여 현재 7가지 염불 발음을 지원: 중국어, 대만어, 일본어, 한국어, 베트남어, 영어, 산스크리트어 (일부 발음은 정확도와 안정성을 테스트하는 중입니다)
- 다국어를 지원하여 현재 7가지 언어 인터페이스를 제공: 번체 중국어, 영어, 일본어, 한국어, 베트남어, 독일어, 프랑스어
- 회향 기능 추가 (내용을 직접 편집 가능)
- 공지 기능 추가 (업데이트 내용 표시)
- 음성 인식 모델을 내장하여, 첫 실행 시 다운로드 불필요

**3. 인터페이스 개선**

- 염불 배경 추가: 동영상 배경 6종, 이미지 배경 4종
- 애니메이션 효과 추가: 회향게가 한 글자씩 채워지는 효과, 회향 완료 애니메이션
- 글꼴 추가: 회향게 글자
- UI를 새롭게 디자인하여 더욱 세련되게
